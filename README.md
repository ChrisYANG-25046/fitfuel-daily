# 🥗 饮食热量追踪器 (Meal Tracker) - 第 1 周垂直切片

基于 **Next.js (App Router) + TypeScript + Tailwind CSS + Supabase Client** 构建的饮食与热量记录应用。

---

## 🚀 核心功能 (第 1 周垂直切片)

1. **输入表单**：输入食物名称（Food Name）和估算热量（Calories / kcal）。
2. **Supabase 插入**：点击提交后，通过 `@supabase/supabase-js` 客户端将数据插入到 Supabase 的 `meals` 数据表中。
3. **列表展示与持久化**：表单下方实时展示已保存的食物列表及累计摄入热量，页面刷新后自动从 Supabase 加载，数据不丢失。
4. **异常与友好提示**：包含未配置环境变量引导、输入有效性校验、加载动画、快捷测试示例等。

## 🛠️ 快速开始

### 1. 安装依赖
本项目已初始化完成依赖，若在其他设备克隆运行：
```bash
npm install
```

### 2. 在 Supabase 创建数据表与策略
登录 [Supabase Dashboard](https://supabase.com/dashboard)，进入项目后打开 **SQL Editor**，运行项目下的 [`supabase/schema.sql`](file:///C:/Users/Chris/.gemini/antigravity/scratch/meal-tracker/supabase/schema.sql) 脚本：

```sql
create table if not exists public.meals (
  id bigint generated by default as identity primary key,
  food_name text not null,
  calories integer not null check (calories >= 0),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 开启行级安全策略 (RLS)
alter table public.meals enable row level security;

-- 允许匿名/公开读取与插入
create policy "Allow anonymous select on meals" on public.meals for select to anon, authenticated using (true);
create policy "Allow anonymous insert on meals" on public.meals for insert to anon, authenticated with check (true);
create policy "Allow anonymous delete on meals" on public.meals for delete to anon, authenticated using (true);
```

### 3. 配置环境变量
打开项目根目录下的 `.env.local` 文件，将你在 Supabase 控制台（`Project Settings` -> `API`）获取到的 URL 与 anon public key 填入：

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### 4. 启动本地开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可开始使用！
