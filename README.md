# 🥗 減量・食事記録アプリ (FitFuel Daily / Meal Tracker)

Next.js (App Router) + TypeScript + Tailwind CSS + Supabase で構築された、減量・PFCバランス管理アプリです。外部有料APIを一切使わずにローカルデータベースのみで軽快に動作します。

---

## 🚀 主な機能

1. **7日間の栄養摂取データ分析＆グラフ可視化（第5週機能）**:
   - **日別カロリー推移バーチャート**: 過去7日間の日別摂取カロリーを棒グラフで表示。目標カロリー（`user_settings`）ラインを点線で水平表示し、目標達成状況を一目で把握可能。記録がない日は 0 kcal としてきれいに描画。
   - **PFC平均バランス（割合）チャート**: 過去7日間の総摂取カロリーに占める三大栄養素（P: たんぱく質 / F: 脂質 / C: 炭水化物）のエネルギー比率をドーナツチャートで視覚化。理想的な減量バランスと比較した管理栄養アドバイスも表示。
   - **サマリーKPIカード**: 「1日平均カロリー」「目標達成率」「記録継続日数」「7日間合計カロリー」をカード形式で集計・表示。
   - **日別詳細一覧テーブル**: 各日をクリックすると該当日をハイライトし、食事件数やPFC内訳を確認可能。
   - **ワンクリックデモデータ投入機能**: テスト用に過去7日分のリアルな食事データを一括生成するボタン付き。
   - **タブナビゲーション & 画面下部表示**: 画面上部のタブ（「食事の記録」/「7日間データ分析」）からワンタップで切り替えられ、記録画面の最下部にも分析ダッシュボードを併設。

2. **スマート検索・リアルタイム自動補完（第4週機能・有料API不要）**:
   - 食品名入力欄に文字を入力するだけで、内蔵ローカルデータベース（50品目以上の日常食・外食・健康食）からリアルタイムにインクリメンタル検索。
   - 「**牛丼**」「**カレー**」「**プロテイン**」「**サラダ**」などを入力すると候補が即座にドロップダウン表示され、タップまたはキーボード操作で**食品名、カロリー、PFC（たんぱく質・脂質・炭水化物）**が自動補完されます。
   - ひらがな・カタカナ・ローマ字相互変換検索に対応。よく検索される定番食品のワンタップタグ付き。

3. **数量・重量解析（自然言語換算）エンジン ＆ 画像/テキスト判定**:
   - ファイル名または入力テキストから「**289g**」「**150グラム**」「**2個**」「**2つ**」などの数値と単位を正規表現で自動抽出。
   - **グラム表記（重量）**: 100gあたりの標準栄養価 × (重量 / 100) で精密換算（例:「牛肉 289g」➔ 723kcal, P:57.8g, F:52.0g, C:1.4g / 「白ご飯 200g」➔ 320kcal, P:5.0g, F:0.6g, C:74.0g）。
   - **個数表記**: 1個あたりの標準栄養価 × 個数 で計算（例:「卵 2個」➔ 160kcal, P:13.0g, F:11.0g, C:0.4g）。
   - 数値未指定時は 100g または 1食分として標準計算。
   - 食材を特定できない場合は `matched: false` を返し、手動入力を安全に維持。

4. **目標カロリー（user_settings）の永続化**:
   - 画面上部の目標カロリー編集機能から数値を変更して「保存」すると、Supabase の `user_settings` テーブルへ自動更新（UPDATE / UPSERT）。
   - ページリロード（F5）後も設定した目標値が確実に維持され、プログレスバーや残りカロリー計算が同期されます。

5. **マイセット（よく食べる食事）機能（第3週機能）**:
   - よく食べる定番メニューをプリセットとして保存し、ワンタップで本日の食事（`meals` テーブル）に即座に追加。

6. **目標進捗バー & PFC サマリー（第2週機能）**:
   - 1日の目標カロリーに対する動的な進捗バーを表示。
   - たんぱく質 (P)・脂質 (F)・炭水化物 (C) の摂取合計をカード形式でわかりやすく可視化。

7. **Supabase クラウド同期（第1週機能）**:
   - 食事記録の追加・一覧取得・削除を Supabase 上で安全に管理。

## 📁 プロジェクト構成

```text
meal-tracker/
├── .env.local             # Supabase URL / Anon Key
├── .env.local.example     # 環境変数テンプレート
├── supabase/
│   └── schema.sql         # meals, presets, user_settings のテーブル定義・RLS ポリシー
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   └── analyze-food-image/
│   │   │       └── route.ts # 食事画像解析 API エンドポイント（完全無料ローカル対応）
│   │   ├── layout.tsx     # ルートレイアウト（日本語化設定）
│   │   └── page.tsx       # メイン UI（記録タブ / 7日間分析タブ / インクリメンタル補完）
│   ├── components/
│   │   └── WeeklyAnalyticsDashboard.tsx # 7日間データ分析ダッシュボード（バーチャート / PFCドーナツ）
│   ├── data/
│   │   └── foodDatabase.ts # ローカル栄養素データベース & インクリメンタル補完エンジン
│   ├── lib/
│   │   ├── analyticsUtils.ts # 7日間データ集計・PFC比率計算ロジック
│   │   └── supabaseClient.ts # Supabase クライアント
│   └── types/
│       ├── analytics.ts   # 7日間分析型定義
│       └── meal.ts        # Meal, Preset, UserSettings 型定義
```

npm run dev
